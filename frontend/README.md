# Stockout Firewall — frontend

React + TypeScript + Vite + Tailwind v4. See the repository root `README.md` and
`docs/DEMO_SCRIPT.md` for context and the full walkthrough.

```
npm install
npm run dev      # http://localhost:5173, expects the backend at VITE_API_BASE_URL (.env)
npm run build    # tsc -b && vite build
```
